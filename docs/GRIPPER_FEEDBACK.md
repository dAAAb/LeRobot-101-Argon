# 夾爪回饋：實測與限制

目前先建立空夾爪的電氣／運動基線，沒有以物件碰撞來測試，也尚未把它換算成力或物件寬度。

2026-09-09 實機紀錄：STS3215 model 777、gripper id 6，讀取馬達原有校準 1456–2983；以 50 ticks/s 執行三次 1520↔1860 空循環。共取得 790 筆讀取成功的樣本，整組暫存器讀取跨度 p95 為 4.37 ms。腕部影像與樣本的時間差 p95 為 133 ms。

基線涵蓋 16 組條件：8 個開啟角度區間、8 個關閉角度區間，每區間寬 40 ticks，均有三次獨立循環支持。資料不足的區間不插值；開始／結束、換向、端點與非巡航樣本不納入。

後續另收集一次全新的空循環，不重新擬合基線：267 筆樣本中，210 筆符合空夾爪基線、57 筆因過渡或證據不足保持 unknown，沒有 stalled 或 contact_candidate。開／合各有 111／109 筆完成基線比較，16 個條件區間都有覆蓋，新資料的 PWM 極性一致率均為 100%。恢復原始上限再次通過。這只驗證此次空循環沒有接觸誤報，不代表真正接觸的靈敏度已通過。

以上原始資料只記錄起始身體姿勢，已封存在 `.runtime/gripper-history/start-pose-only-20260909/`。加入逐筆姿勢驗證後，又重新實測三輪，取得 781 筆樣本及 16 個區間；手肘最大變化 4 ticks，其餘身體關節未變。新基線的獨立第四輪共 262 筆：205 free、57 unknown、0 stalled、0 contact_candidate，開合各 107 筆完成比較。兩次新量測都確認恢復 PWM 500，最新中和位置為 1525。新版檢查不會把缺少逐筆姿勢的舊紀錄自動升級。

## 暫存器意義

- 56：實際位置；42：當下實際讀回的移動目標，不能以整段最終終點替代。
- 60：帶符號的驅動 PWM，符號位 bit 10。此次實測 PWM 與編碼器運動的方向相反，一致率 99.86%；判讀時使用獨立的 polarity=-1 對應，不改 closing_sign=-1。
- 69：帶符號電流讀值，符號位 bit 15，6.5 mA/count。本次讀到 0、1、2；讀值變化不等於已校準接觸力。
- 48：RAM 驅動 PWM 上限，0.1%/count；不是「力矩百分比」。本機原值 500，量測暫降為 100。
- 65：保護狀態；66 是 moving，不能混用。任何保護位元或通訊異常皆不可當成有效接觸證據。

只在型號、模式與校準一致時操作。沒有寫入 EEPROM、改動其他關節的 PWM 上限或提高測試輸出。

## 中斷與恢復

改動 48 前，先原子寫入並 fsync 本機恢復紀錄。完成時在低上限 100 下將未完成目標改為實際位置，確認目標讀回、停止移動與連續三筆位置穩定，才恢復並讀回原值 500。本次完整通過，結束位置與目標均為 1525。

通訊／馬達異常保留 pending 紀錄並鎖定停止；重新啟動、begin、resume 都不能自動跳過。`recover_gripper_power` 是明確的工程恢復操作：重新查驗硬體，在低上限下重新消除未完成目標，再恢復原值；完成後仍保持停止。位置命令可能解除某些馬達保護，因此 fault 狀態禁止寫 Goal_Position，包括 hold。

active／pending／不完整紀錄存在時，普通 hold 也跳過夾爪 Goal42，讓低輸出中和流程處理；健康身體關節仍嘗試保持。這涵蓋「500 已寫入，但確認回覆遺失」的情況。三項假 SDK 整合測試驗證故障清理、重复停止與重啟不會繞過此限制；沒有在實機上刻意製造失聯。

停止事件與通訊錯誤同時發生時，以原始錯誤種類決定處理，不能因為收到 stop 就把通訊故障視為正常取消。

## 疑似接觸判讀

`server/contact.py` 比較相同角度区間、方向、速度與 PWM 上限的基線。只有持續的關閉停滯、超出基線的跟隨誤差與 PWM 同時成立，才回報 `contact_candidate`。其他狀態是 unknown、free 或 stalled；free 僅表示與空夾爪基線相符。

每筆資料還必須包含同一讀取時間窗內的五個身體編碼器，並符合凍結基線的姿勢條件。任何一軸超過 4 ticks（約 0.35 度），或姿勢資料缺失，就清除累积的接觸證據；不同重力方向不可混用。4 ticks 是保守的重用限制，並不是已證實這個範圍內的摩擦完全不變。重新量測前，驗證模式也會在送出位置／扭力命令前檢查起點。

`contact_candidate` 不是成功抓握，`true_grasp` 永遠是 false，`force_estimate` 永遠為 null。近端點區域、反轉、過期樣本、不同輸出上限和未量測角度區間都不外推。真正的物件接觸、雙側接觸、抓取後物件跟隨與放置仍需另行驗證。

URDF 的固定夾爪末端座標不是兩爪中心。模型零度仍有間隙，馬達校準下限也不等於接觸零位；沒有以這些假設計算物件寬度。
